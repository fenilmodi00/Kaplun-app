## Key Decisions

1. **`uniwind-env.d.ts` created** — Uniwind's RN component type augmentation (`className` on ViewProps, TextProps, etc.) lives in `uniwind/types`. A `/// <reference types="uniwind/types" />` directive replaces the deleted `nativewind-env.d.ts`.

2. **ScrollView `contentContainerClassName` handling** — Only flattens `contentContainerStyle` when `contentContainerClassName` is actually provided. When not provided, passes `contentContainerStyle` through as-is to preserve array structure that `screen-shell.test.tsx` depends on.

3. **`useThemeScheme` kept as API** — Rewired internally to derive from `useThemeMode().mode` (from `panelui-native`). All call sites updated to use `useThemeMode().mode` directly per spec, but `useThemeScheme()` remains for `useThemeColors()` and test mocks.

4. **`useThemeColors()` stays with static maps** — `lightColors`/`darkColors` static maps selected by `useThemeMode().mode`. NOT re-implemented with 24 `useCSSVariable()` calls (would violate rules of hooks).

5. **Profile theme toggle** — No changes needed to `src/screens/profile/index.tsx`. The toggle uses `useThemePreference()`/`setThemePreference()`, and `setThemePreference` now calls `Uniwind.setTheme` (step 8 seam). The toggle drives Uniwind immediately.
